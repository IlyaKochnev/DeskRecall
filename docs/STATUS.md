# Состояние разработки DeskRecall

Версия 0.3.0 от 29 октября 2026 года собирает окна через WindowServer и дополняет их данными Accessibility. Исправлен пропуск окон Chrome, Терминала, Календаря и Мониторинга системы на неактивных столах.

## Проверка на текущем Mac

Выполнено сохранение текущей раскладки, повторное чтение профиля и сверка по системным идентификаторам окон. Отдельный инструмент независимо запросил список WindowServer и принадлежность окон столам. На момент итоговой проверки в системном списке и файле совпало 29 окон, пропусков 0. Прочитаны все шесть существующих столов.

| Приложение | Окон в системе | В профиле | Пропущено |
| --- | --- | --- | --- |
| Chrome | 5 | 5 | 0 |
| Терминал | 1 | 1 | 0 |
| Календарь | 4 | 4 | 0 |
| Мониторинг системы | 1 | 1 | 0 |

Числа включают вспомогательные окна приложения, привязанные к столам. Окна не перемещались, столы не переключались. Сначала было проверено 28 окон; появившееся во время работы окно учтено повторным снимком из 29 окон. Результат относится к моменту итогового сохранения.

## Реализация

WindowServer задаёт основной список и геометрию. Отсутствие AX объекта не исключает окно из сохранения. Системный window ID связан с PID, временем запуска процесса и сеансом загрузки macOS, чтобы не переносить идентичность на другой процесс или после перезагрузки.

Схема профиля 3 сохраняет принадлежность каждого системного окна к столам и снимок существующих столов. Профили схем 1 и 2 читаются; предыдущее сохранение остаётся в резерве. Данные AX присоединяются по точному системному ID или однозначной геометрии. Неоднозначные совпадения не используются для управления.

Сбор и сохранение работают без Accessibility, управление окнами требует его отдельно. Все 21 автоматическая проверка пройдены, release сборка и подпись проверены. Версия 0.3 запущена.

## Границы результата

Подтверждена полнота сохранения пользовательских окон на текущих столах в момент итогового снимка. Меню, поверхности входа, Dock и технические окна без принадлежности столам не входят в целевой список. Новые окна после снимка требуют нового сохранения.

Для привязки к Spaces используется приватный read-only адаптер SkyLight. Другая версия macOS требует повторной проверки; отсутствие возможностей отражается в отчёте. SIP и системные настройки не менялись, Screen Recording не запрашивался.

Сохранение всех окон не означает возможность сразу перемещать каждое из них. Окна без AX объекта сохраняются, но изменение их геометрии пока возвращает явное ограничение; уже совпадающая геометрия может быть проверена через WindowServer. Перенос между Spaces и перестройка порядка столов не реализованы. Автозапуск, Developer ID и notarization остаются отдельными задачами.

## Разработка восстановления версии 0.4

Добавлен DesktopRestorer: подготовка столов, сопоставление по UUID монитора и порядковому номеру, перенос сохранённых окон, восстановление геометрии и проверка результата по WindowServer. В рамках одного сеанса старые Space ID используются только при совпадении сохранённой логической позиции; после смены ID разрешение выполняется по монитору и номеру. Случайный другой стол не подставляется.

Нативный адаптер использует мост WindowManager, доступный на текущей macOS 26.6.2 при включённой SIP. На временном окне подтверждён перенос между столами и мониторами с возвратом. На временном пустом столе подтверждены создание, перенос между дисплеями и удаление только тестового стола; исходных столов до и после проверки — шесть. Изменение размеров через этот мост не подтверждено и не используется: геометрия меняется через AX.

Для окон неактивных столов добавлен ограниченный поиск AX объекта по системному ID. При отказе клиента возможна временная постановка только нужного окна на видимый стол с возвратом на целевой. В каждом случае результат проверяется по геометрии и принадлежности столу. При смене экранов устаревшая задача отменяется, а новый профиль выбирается после стабилизации.

23 автоматические проверки прошли. Сборка 0.4.0 запущена. Фактический тест изменения геометрии четырёх приложений и физический цикл отключения и подключения экранов ещё ожидают проверки. Для AX операций новой сборке требуется повторно выдать Accessibility. До окончания этих испытаний полное восстановление не считается прошедшим приёмку.


## Проверка 0.4.1 и подготовка 0.4.2

В испытании 0.4.1 подтвердилось изменение геометрии и рабочего стола основных окон Chrome и Календаря. Терминал ограничивает ширину шагом сетки символов; для контрольного изменения выбран шаг 11 points. Chrome не принял произвольное уменьшение высоты максимизированного окна, поэтому испытание 0.4.2 меняет ширину с сохранением высоты. Одно вспомогательное окно Chrome управляется самим приложением: его геометрия после возврата отличалась от снимка. Это считается ограничением, а не успехом. Полное восстановление всех вспомогательных окон пока не подтверждено.

В 0.4.2 исправлено удержание AX объектов при переносе между столами: общий WindowService используется при сканировании и восстановлении, сохраняются ранее полученные объекты. Для резервного получения объекта на активном столе добавлена активация целевого приложения с возвратом предыдущего. 23 автономные проверки прошли. Выпущенная локальная сборка ожидает повторного разрешения Accessibility и реального испытания. Исходный пользовательский файл профиля после диагностического эксперимента возвращён побайтно; резервные снимки находятся отдельно в Application Support/DeskRecall/Recovery.


## Реальное испытание 0.4.2 — 29 октября 2026

Accessibility обновлён через штатный интерфейс macOS после подтверждения владельцем Mac. Финальное встроенное испытание: passed=true; сохранено 31 окно на шести столах, verified=31, constrained=0, skipped=0. Независимый системный снимок после восстановления: missing=0, wrongGeometry=0, wrongSpace=0. Реально изменены ширина, координаты и принадлежность столу основных окон Chrome, Терминала, Календаря и Мониторинга системы; затем восстановлен весь свежий снимок. Повторный возврат также verified=31/31. Основной пользовательский профиль испытанием не перезаписывается.

Предыдущий проход 33 окон содержал временное системное окно настроек, исчезнувшее между снимками; это не было объявлено успехом. Первый проход также выявил отсутствие готового AX объекта Мониторинга системы; после инициализации его интерфейса управление удалось. Гарантия управления каждым приложением сразу после запуска пока не установлена. Физический цикл подключения экрана ещё не проведён. Старые профили схемы 1 необходимо сохранить заново для получения привязок всех окон к столам.

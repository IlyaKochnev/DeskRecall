# Возможности macOS для DeskRecall

Расположение обычных окон и управление виртуальными столами требуют разных интеграций. Для MVP сначала нужно измерить доступные операции на целевой macOS при включённой SIP. Перечень ниже — техническая основа и задания прототипа, а не результаты проверки приложения.

## Подтверждённая основа

Apple предоставляет Accessibility API для чтения и записи атрибутов UI элементов и проверки доверия процесса. Геометрия окна изменяется только если приложение поддерживает запись соответствующих атрибутов. [Accessibility API](https://developer.apple.com/documentation/applicationservices/1460720-axisprocesstrusted).

Для изменения конфигурации дисплеев есть уведомление `NSApplication.didChangeScreenParametersNotification`. На него можно опереться при hotplug. [Документация Apple](https://developer.apple.com/documentation/AppKit/NSApplication/didChangeScreenParametersNotification?changes=_6).

Для получения UUID дисплея существует `CGDisplayCreateUUIDFromDisplayID`; его наличие не гарантирует неизменность идентичности при любом переходнике. [Документация ColorSync](https://developer.apple.com/documentation/colorsync/cgdisplaycreateuuidfromdisplayid%28_%3A%29).

Apple описывает пользовательскую работу со Spaces через Mission Control и назначение приложения столу. Это не API для полного восстановления структуры Spaces. [Руководство Apple](https://support.apple.com/guide/mac-help/work-in-multiple-spaces-mh14112/mac).

## Главный риск

В исследованных публичных API нет документированного полного набора операций для восстановления структуры Spaces. Поэтому не закладываем такой механизм как гарантированно доступный. У yabai документированы операции со столами; для создания, перестановки и переноса столов между дисплеями указано требование частичного отключения SIP. Требования различаются по операциям: не следует переносить это утверждение на любую команду перемещения окна. [Команды yabai](https://github.com/asmvik/yabai/blob/master/doc/yabai.asciidoc), [SIP и scripting addition](https://github.com/asmvik/yabai/wiki/Disabling-System-Integrity-Protection).

Это основание исследовать отдельный backend, а не основание отключать защиту или обещать совместимость. Приватные SkyLight или CGS API могут меняться между версиями macOS; допустимость и работоспособность каждой операции проверяются отдельно. Автоматизация Mission Control зависит от интерфейса, анимаций, языка и фокуса и требует собственного прототипа.

## Матрица прототипа

| Операция | Начальная гипотеза | Что зафиксировать |
| --- | --- | --- |
| Прочитать окна активного стола | Accessibility | Полнота и перечень исключений |
| Прочитать окна неактивных столов | Требует проверки по приложениям | Отличие от видимых окон, доступ без активации |
| Изменить положение и размер | Accessibility для поддерживаемых окон | Атрибуты, координаты, таймауты |
| Определить монитор после hotplug | NSScreen и UUID | Повторяемость через порты и док |
| Прочитать состав и порядок Spaces | Экспериментальный backend | Публичный или приватный механизм, права |
| Определить стол каждого окна | Экспериментальный backend | Несколько столов, окна на всех столах |
| Переместить окно на другой стол | Экспериментальный backend | SIP, активация, стабильность |
| Создать и переставить столы | У yabai имеются требования к SIP | Реальная доступность при включённой SIP |
| Перенести стол между экранами | У yabai имеются требования к SIP | Поведение при отключении дисплея |

Для каждого эксперимента записать версию ОС и backend, состояние SIP, настройки «Мониторы с отдельными пространствами» и автоматической перестановки столов, исходное состояние, действие, ожидаемый и фактический результат. Тестировать сначала в отдельном пользовательском сеансе или с тестовыми окнами; сохранять способ ручного возврата.

## Выбор подхода

Приоритет — собственное нативное приложение с включённой SIP. Подтверждённые публичные API составляют базовый режим. Если приватный адаптер работает без изменения защиты, его можно рассматривать как экспериментальную возможность с ограничением по версии macOS. Если доступна только автоматизация Mission Control, измерить её надёжность и видимые переключения прежде, чем включать автоматически.

Внешний yabai — кандидат для сравнения и возможной опциональной интеграции. Он не является установленной зависимостью проекта. Зависимость от scripting addition и изменения SIP требует отдельного решения пользователя; в текущей подготовке таких действий нет.

Если надёжный способ не найден, выпустить ограниченный MVP A с геометрией окон и сохранить Spaces как незакрытую задачу. Даже доступ к окнам на всех неактивных столах следует подтверждать отдельно.

## Решение после прототипа

Статус: для первого прототипа выбран MVP A с включённой SIP. Проверено чтение дисплеев и приватного списка Spaces; AX и операции изменения столов ещё не проверены. Подробности — [результат исследования](../spikes/spaces/RESULTS.md).

Подтверждённая среда — macOS 26.6.2 на Apple Silicon с включённой SIP. Приватное чтение Spaces изолировано в диагностическом инструменте; приложение использует публичные API и не заявляет поддержку восстановления столов. Доступность операций изменения и результаты циклов подключения следует дополнять в `spikes/spaces/RESULTS.md` по мере практических проверок.

## Расширение сохранения версии 0.2

29 октября 2026 года удалён фильтр видимых окон. Чтение использует AXWindows каждого подходящего приложения, а системный список optionAll включает видимые и невидимые окна. Само наличие окна в CG списке не означает доступности AX геометрии. Полнота охвата проверяется отдельно в графическом сеансе после выдачи доступа новой сборке.

Источники: [AXWindows](https://developer.apple.com/documentation/applicationservices/kaxwindowsattribute?changes=_10%2C_10), [CGWindowList optionAll](https://developer.apple.com/documentation/coregraphics/cgwindowlistoption/optionall?language=_4).

## Системный сбор версии 0.3

29 октября 2026 года подтверждено, что AXWindows не обеспечивает полного списка неактивных столов. В основу сбора перенесён CGWindowListCopyWindowInfo optionAll. Привязки окон читаются через SLSCopySpacesForWindows, список столов — через CGSCopyManagedDisplaySpaces. Адаптер использует только чтение; операции изменения столов не загружаются.

На macOS 26.6.2 при включённой SIP и без Accessibility сохранено 29 окон на шести столах. Независимая сверка по системным ID не обнаружила пропусков, в том числе у Chrome, Терминала, Календаря и Мониторинга системы. Возможность восстановления каждого окна без AX этим не подтверждена.

# DeskRecall

Локальное macOS приложение для сохранения раскладки окон под разные наборы подключённых экранов. После подключения или отключения монитора приложение автоматически выбирает соответствующий сохранённый профиль.

## Текущее состояние

Реализован первый прототип MVP версии 0.5.1: приложение в строке меню, проверка Accessibility, сохранение профилей, ручное восстановление, автоматическое восстановление после стабилизации экранов, отмена устаревших операций, резерв предыдущего профиля и отчёты о пропусках. Исходники собираются через Swift Package Manager; отдельный проект Xcode не требуется.

С версии 0.3.0 основа сохранения — системный список WindowServer, включая окна неактивных столов. Accessibility дополняет его данными и объектами управления, но отсутствие окна в AXWindows больше не исключает его из профиля. Сохраняются системный идентификатор окна, процесс и его запуск, сеанс загрузки macOS, геометрия, монитор и существующая принадлежность к Spaces. Заголовки документов не требуются.

Сохранение и проверка охвата работают без Accessibility. Для перемещения окон при восстановлении Accessibility по-прежнему нужен. Версия 0.4.2 ищет объект управления по системному идентификатору и сохраняет его при переносе окна между столами. Если приложение запрещает изменение геометрии, результат отмечается как ограничение.

Системные поверхности входа, Dock, меню и скрытые технические окна без привязки к столу исключаются. Окна приложений на столах, в том числе вспомогательные, учитываются. Чтение привязок к Spaces использует адаптер SkyLight. Экспериментальный нативный мост переносит окна и столы между мониторами и создаёт недостающие обычные столы. После каждой операции проверяются фактические привязки и геометрия; при недоступном адаптере выдаётся явное ограничение. Проверка 1 ноября: по профилю предыдущей загрузки восстановлены все 10 однозначно распознанных окон из 29 записей; 19 закрытых или нераспознанных записей остались пропущенными. Перенос столов по содержимому проверен на текущих подключённых экранах. Повторная физическая перезагрузка Mac в ходе этой проверки не выполнялась.

Сборка и автономные проверки выполнены на Apple Silicon с macOS 26.6.2 и Swift 6.1.2. Указанная в пакете минимальная версия macOS 14 — цель совместимости; отдельной проверки на macOS 14 ещё не было. На текущем Mac проверено реальное сохранение и независимая сверка: 29 системных окон на шести столах, пропусков 0. Для самой проверки Accessibility не требовался. Результат относится к моменту снимка.

## Восстановление после перезагрузки (0.5.0)

Системные идентификаторы действуют только в пределах загрузки macOS. Между загрузками сначала используются сохранённые отпечатки документов, идентификаторов и заголовков. При чтении окон для нового сохранения дополнительно запрашиваются объекты AX неактивных столов без переключения столов; исходные заголовки и пути по-прежнему не записываются.

Для существующих неполных профилей добавлен резервный подбор: единственное окно приложения с обеих сторон либо единственное доминирующее обычное окно (площадь больше следующего более чем в четыре раза). Это подбор по приложению, а не доказательство тождества документа; он отдельно отмечается в журнале `legacyIdentityFallback`. Сопоставление сопоставимых нескольких окон и вспомогательных поверхностей по одному размеру не выполняется. Закрытые окна не открываются заново.

После перезагрузки столы определяются по группам сопоставленных окон. Группа с признаками нескольких сохранённых столов считается объединённой: она не переносится целиком по этому признаку. Идентифицированные столы резервируются до поиска по номеру; затем восстанавливаются монитор и порядок, после чего проверяется вся раскладка столов. Геометрия окон дополнительно проверяется общей итоговой сверкой с повторными попытками после задержанных изменений приложений. Окна, занимавшие весь физический экран, сохраняют это положение независимо от размеров Dock. Окна объединённых групп распределяются отдельно. Дополнительные существующие столы не удаляются и могут оставаться после сохранённых.

Старые профили читаются без миграции на диске. Подтверждение действительности резервного сопоставления после перезапуска приложения и изменения набора документов всё ещё зависит от доступных признаков; неоднозначные окна остаются пропущенными.

## Вспомогательные окна и разбор пропусков (0.5.1)

В профиле дополнительно сохраняются уровень окна WindowServer и прозрачность. Эти необязательные поля читаются без изменения схемы 3; старые профили остаются совместимыми. Для старых записей без AX признаков добавлен подбор небольших и специальных окон по приложению, совместимому классу и точным размерам с обязательной взаимной уникальностью. Несколько одинаковых сохранённых записей не назначаются одному текущему окну. Это отдельный резервный способ, отмечаемый в журнале `auxiliaryIdentityFallback`.

Широкие панели, принадлежащие приложению, дополнительно распознаются по однозначному смещению относительно уже найденного главного окна и общему рабочему столу. Такие эвристические связи не используются как основания для переноса всего стола. Для панелей с размером, зависящим от содержимого, проверяется принадлежность столу, а несовпадение геометрии остаётся явным ограничением. Прозрачные поверхности можно перемещать через AX без показа и активации.

Отчёт диагностики содержит запись по каждому сохранённому окну: найденное окно, способ сопоставления, отсутствие текущих окон приложения, неустановленное соответствие или неоднозначность. Отсутствие соответствия больше не трактуется как доказательство закрытия. После восстановления отдельно проверяются точная геометрия и множество столов.

## Первый запуск

1. Открыть `dist/DeskRecall.app`. Приложение появляется в строке меню под значком нескольких окон.
2. Для сохранения доступ не требуется. Для восстановления выбрать «Предоставить доступ…» и включить DeskRecall в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Приложение проверяет изменение доступа каждые две секунды.
3. Расставить окна на всех столах и нажать «Сохранить».
4. Изменить расположение окон и проверить «Восстановить сейчас».
5. Отключить монитор, расставить окна на MacBook и сохранить второй профиль. При следующем подключении приложение выберет профиль внешнего экрана; при отключении — профиль MacBook.

Для конфигурации без сохранения окна не перемещаются. Сохранение всегда запускается вручную. Если часть прежних окон отсутствует, приложение запрашивает явную замену профиля; предыдущее сохранение остаётся в резервной копии. Если снимок содержит ошибки чтения, приложение предлагает отмену или явно подтверждённое сохранение доступной части.

«Проверить охват окон…» выполняет чтение без сохранения и показывает системные окна и количество окон без объекта AX. Состояния минимизации и возможности управления известны только для окон, предоставленных через AX; невидимость сама по себе не означает минимизацию. Такая же проверка выполняется после запуска, включая случай отсутствующего доступа. «Последний отчёт…» показывает ограничения и причины пропусков. «Сводка за 48 часов…» показывает накопленную статистику. «Открыть папку журнала» открывает локальные JSONL файлы для подробного разбора. «Восстанавливать автоматически» можно отключить, сохранив ручную команду. Автозапуск при входе пока не реализован.

## Сборка и проверки

Требуются Command Line Tools со Swift 6 или полный Xcode. Внешних зависимостей нет.

```sh
scripts/test.sh
scripts/build-app.sh release
```

Приложение появится в `dist/DeskRecall.app`. `scripts/test.sh` запускает 29 автономных проверок без XCTest, которого нет в установленном Command Line Tools. Они проверяют сопоставление окон, идентичность конфигураций, координаты, поколения операций и сохранность файлов. Проверки не управляют настоящими окнами.

Для окружения Codex с ограниченным доступом к системным каталогам сборки использовалось:

```sh
DESKRECALL_DISABLE_PACKAGE_SANDBOX=1 scripts/test.sh
DESKRECALL_DISABLE_PACKAGE_SANDBOX=1 scripts/build-app.sh release
```

Эта переменная отключает только дополнительную изоляцию запуска манифеста SwiftPM. Она не меняет SIP и разрешения приложения. Кэши сборки находятся в `.build/` проекта.

Пакет подписывается ad hoc для локального использования. Для распространения нужен собственный Developer ID и notarization. Переменная `DESKRECALL_SIGN_IDENTITY` задаёт другую подпись. После пересборки ad hoc macOS может потребовать повторно предоставить Accessibility. Перед заменой работающего приложения сначала завершить его через меню.

## Журнал работы

Начиная с версии 0.3.0 приложение автоматически ведёт локальный журнал в `~/Library/Logs/DeskRecall/`. Формат — JSONL: отдельная JSON запись на каждой строке, время UTC. Сводка в меню охватывает последние 48 часов. Подробности — [LOGGING.md](docs/LOGGING.md).

Сохраняются запуск и завершение, изменения экранов и доступа, причины автоматического восстановления, выбранная версия профиля, результаты по окнам, ошибки и длительность операций. Каждые пять минут работающего приложения добавляется отметка активности. Старые события из версии 0.1.0 восстановить нельзя.

Журнал ограничен 14 календарными датами UTC и 32 файлами по 1 МиБ; при достижении лимита более старые файлы удаляются раньше. В нём нет заголовков окон, путей документов, содержимого окон и исходных UUID экранов. Есть bundle identifier приложений, обезличенные идентификаторы окон и конфигураций, целевая и проверенная геометрия.

Успех означает проверку геометрии сразу после применения с допуском 4 points. Дальнейшие самопроизвольные или ручные перемещения окон не отслеживаются. Для сбора статистики приложение должно оставаться запущенным; после перезагрузки его пока нужно запускать вручную.

## Диагностика и данные

Профили находятся в `~/Library/Application Support/DeskRecall/Profiles/`. Каждый набор экранов имеет отдельный JSON файл; предыдущая версия хранится рядом с расширением `.backup`. Запись атомарная. Профили версий 1 и 2 читаются без изменений. Новое сохранение использует схему 3 с системной идентичностью окна и привязками к столам; старая версия программы откажется перезаписывать такой профиль. Неизвестные будущие схемы и повреждённые файлы не перезаписываются. Для намеренного сброса повреждённого профиля его можно переместить из папки профилей, сохранив копию.

В профиле сохраняются UUID экранов, геометрия окон, идентификаторы приложений и SHA256 отпечатки доступных признаков окна. Исходные заголовки и пути документов не сохраняются. Отпечатки не являются шифрованием. Сеть и облако не используются.

Безопасная диагностика не меняет окна и не запрашивает доступ автоматически:

```sh
scripts/swiftw build --product DeskRecallProbe
.build/debug/DeskRecallProbe
.build/debug/DeskRecallProbe --probe-spaces
```

Последняя команда отдельно проверяет чтение списка Spaces. Для восстановления версия 0.4 использует отдельный экспериментальный мост изменения Spaces; перечисленные диагностические команды только читают состояние. Из изолированного сеанса без WindowServer диагностика может вернуть ноль экранов; это не означает отсутствия физических мониторов.

# Работа над DeskRecall

Следовать глобальным инструкциям пользователя, включая маршрутизацию ссылок wiki.yandex.ru, tracker.yandex.ru, datalens.ru, gitlab.lamoda.tech, netbox.lamodatech.ru и app.pachca.com через MCP соответствующего сервиса. Если MCP недоступен или не поддерживает операцию, сообщить об этом до перехода к браузеру.

Перед реализацией читать README.md, docs/PLAN.md и docs/FEASIBILITY.md. Полное восстановление Spaces не подменять восстановлением геометрии окон.

Использовать Swift и нативные API macOS. Изолировать экспериментальные API Spaces за интерфейсом с явными возможностями. Сначала выполнять этап 0; не обещать операции, не проверенные на целевой ОС.

Системную защиту, настройки Mission Control и рабочие столы пользователя не менять в рамках подготовки или исследования без соответствующей авторизации. Для базового режима достаточно пользовательского разрешения Accessibility; дополнительные разрешения обосновывать выбранным механизмом.

Не сохранять в репозитории реальные профили, заголовки окон, пути документов или диагностические дампы пользователя. Для Fixtures использовать синтетические данные. При реализации сохранять профили только по явной команде, автоматически восстанавливать только существующий профиль точной конфигурации, неоднозначные окна пропускать.

Документацию вести на русском. Состояние проекта, реальные ограничения и результаты проверок обновлять вместе с изменениями.

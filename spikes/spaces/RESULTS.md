# Проверка возможностей macOS для DeskRecall

Дата: 28 октября 2026 года. MacBook Apple Silicon, macOS 26.6.2 build 25G83, Swift 6.1.2. Использовались Command Line Tools; полного Xcode и доступного сертификата Developer ID нет. SIP включена.

## Фактические результаты

| Проверка | Результат |
| --- | --- |
| Сборка нативного приложения через SwiftPM | Успешно без полного Xcode |
| Локальная подпись ad hoc | Успешно; Developer ID не настроен |
| Доступ Accessibility для диагностического процесса | Не предоставлен |
| Чтение NSScreen в графическом сеансе | Два экрана, расширенный режим, идентификация полная |
| Приватное чтение списка Spaces | Успешно; два дисплея, по три стола на каждом |
| Чтение окон через AX | Не проверено из-за отсутствия Accessibility |
| Изменение геометрии тестового окна через AX | Не проверено из-за отсутствия Accessibility |
| Принадлежность окна к столу | Не проверена |
| Перемещение окна между столами | Не проверено |
| Создание и перестановка столов | Не проверены |
| Перенос стола между дисплеями | Не проверен |
| Стабильность UUID через док и разные порты | Требуется реальное переподключение |
| Настройки Mission Control и Stage Manager | Не менялись; матрица совместимости не проверена |

Приватное чтение выполнено отдельным `DeskRecallProbe --probe-spaces`: динамически загружается SkyLight и вызываются `CGSMainConnectionID` и `CGSCopyManagedDisplaySpaces`. Вывод ограничен числами и состояниями; идентификаторы столов, названия приложений и окон не сохранялись. Операций изменения Spaces не было.

Первый запуск из изолированного процесса не имел доступа к WindowServer и вернул ноль экранов. Повторный запуск с доступом к графическому сеансу подтвердил два дисплея и чтение Spaces. Поэтому нулевой результат из изоляции не используется для оценки физических экранов.

## Принятое решение для прототипа

Разрабатывать MVP A с публичными API для геометрии видимых окон и с включённой SIP. В приложение включён `UnsupportedSpacesProvider`, который явно сообщает об отсутствии поддержки восстановления Spaces. Чтение через приватный API из исследовательского инструмента не используется как доказательство возможности полного восстановления столов.

Этап 0 выполнен частично: сборка и чтение дисплеев проверены; AX и операции изменения Spaces требуют продолжения исследования. Требование полного восстановления виртуальных столов остаётся открытым. Установка yabai, системных дополнений и отключение SIP не выполнялись.

## Следующая проверка

Предоставить Accessibility готовому `.app`, сначала проверить ручное восстановление тестовых окон, затем выполнить основной цикл приёмки с реальным подключением монитора. После этого отдельно исследовать изменение принадлежности окна к Spaces и порядка столов на тестовом рабочем пространстве. Результаты записывать по каждой операции, без обобщения успешного чтения на возможность записи.
